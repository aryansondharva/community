# Code of Conduct

## Our Pledge

We are committed to making participation in this project a respectful and harassment-free experience for everyone.

## Expected Behavior

- Be respectful and kind
- Help beginners and new contributors
- Give constructive feedback
- Keep discussions useful and friendly

## Unacceptable Behavior

- Harassment or abusive language
- Spam or fake links
- Disrespectful comments
- Personal attacks
- Adding false community information

## Our Responsibility

Project maintainers may remove content or contributions that break these rules.

## Scope

This Code of Conduct applies to this repository, issues, pull requests, and discussions related to this project.
