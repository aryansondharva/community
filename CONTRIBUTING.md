# Contributing Guide 🤝

Thank you for showing interest in contributing to **Community Directory**.

This repository is made to help students, developers, designers, and tech learners find the right community near their city.

---

## What can you contribute?

You can contribute by adding:

- A new community
- A new college society
- A new city
- Correct website links
- Correct social media links
- Communication channel links
- Missing details
- Spelling and formatting fixes

---

## How to add a community

1. Fork this repository
2. Go to the `data/` folder
3. Open the correct city file
4. Add your community in the correct table
5. Save your changes
6. Create a Pull Request

---

## Open Community Format

```md
| Community Name | Website | Type of Community | Communication Channel | Social Media Link |
|---|---|---|---|---|
| Example Community | https://example.com | Developer | Telegram | https://instagram.com/example |
```

---

## College Society Format

```md
| Community Name | College Name | Website | Type of Community | Communication Channel | Social Media Link |
|---|---|---|---|---|---|
| Example Club | ABC College | https://example.com | Developer | Discord | https://instagram.com/example |
```

---

## Rules

Please follow these simple rules:

- Add only real and active communities
- Do not add fake or spam links
- Add official links if possible
- Add the community in the correct city file
- Keep the table format clean
- Use `-` if information is not available
- Do not remove other communities without a valid reason

## Adding a new city

If your city is not available:

1. Create a new file in the `data/` folder
2. Name it like this:

```txt
city-name.md
```

Example:

```txt
rajkot.md
```

3. Add the city link in `README.md`

Example:

```md
- [Rajkot](data/rajkot.md)
```
